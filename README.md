# Zayan Shibly — Portfolio

A personal portfolio for Zayan Shibly, built with HTML, CSS, and vanilla JavaScript. No frameworks or build step.

## Open the site

Double-click `index.html`, or drag it into a browser.

## Edit projects later

Project cards are generated from the `projects` array at the top of `script.js`. Add or replace an object there instead of rewriting the HTML.

Placeholder email, GitHub, and LinkedIn links are marked in the Contact section. Replace them with real details when you have them.
